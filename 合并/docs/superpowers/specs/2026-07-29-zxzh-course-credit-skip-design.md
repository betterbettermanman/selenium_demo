# ZXZH 单课认定学时跳过优化

日期：2026-07-29  
状态：已确认（方案 A）

## 背景

专题页（如 `https://basic.smartedu.cn/training/2026jjsqpx`）每门课程卡片展示：

`已认定 X.XX / 认定 Y 学时`

一门课认定已满后，无需继续播放该课剩余视频，应立即换下一门。

## 目标

- 播课前 / 回专题页后：若该课 **已学习 > 认定**，跳过该课（实际学时通常略高于认定，尽早换章）。
- 兜底：若 **已认定 >= 认定**，同样跳过。
- **任务完成条件不变**：专题累计学时 ≥ 10（`CREDIT_TARGET`）。

## 非目标

- 不改变 `courses` 配置格式。
- 不改为「全部课程认定满即完成任务」。

## 方案

在 `ZxzhTaskRunner._play_training_loop` 中，打开课程详情前调用 `_is_course_credit_done(title)`：

1. 从专题页 `body` 文本定位课程 `title`。
2. 在标题后窗口内匹配：
   - `已学习\s*([\d.]+)`
   - `已认定\s*([\d.]+)\s*/\s*认定\s*([\d.]+)\s*学时`
3. `已学习 > 认定` 或 `已认定 >= 认定` → 跳过；解析失败 → 不跳过，按原逻辑播未完成小节。

## 风险

- 标题与页面文案不完全一致时可能匹配失败（兜底：不跳过）。
- 学时刷新有延迟；一节播完后回专题页短暂等待再读数（沿用现有等待）。

# 国家中小学智慧教育平台（ZXZH）课程学习设计

日期：2026-07-28  
状态：已确认（待实现）

## 背景

ZXZH 执行器已支持账号密码 + 腾讯滑块自动登录。需补齐 **教师研修课程学习**，对齐参考实现 `寒暑假期教师研修/main.py`，以专题页为例：

- 专题：`https://basic.smartedu.cn/training/2026jjsqpx`（2026 暑期教师研修）
- 目标学时：累计 **10** 学时（含必修与选修内容，由平台记录）

## 目标

1. 登录成功后进入专题页，按任务配置播课。
2. 以专题页 **累计学时达到 10** 为任务完成条件。
3. 播放逻辑对齐参考脚本：新标签打开课程、展开目录、播未完成视频、2 倍速、「再学一遍」后回专题页刷新学时。

## 非目标

- 自动考试 / 答题 / 证书下载
- 运行时自动爬取专题页全部课程列表（本期由任务 `courses` 提供）
- 保证无头模式稳定（联调默认有头）

## 方案选择

扩展现有 `ZxzhTaskRunner`（方案 A）：登录后接上播课循环，不另起执行器。

## 配置约定

| 字段 | 含义 | 示例 |
|---|---|---|
| `task.class_id` | 专题页 URL | `https://basic.smartedu.cn/training/2026jjsqpx` |
| `task.courses` | JSON 数组，驱动播哪门课 | `[{"title":"大力弘扬教育家精神","url":"https://basic.smartedu.cn/teacherTraining/..."}, ...]` |

每门课至少包含：

- `title`：课程标题（用于日志与进度匹配）
- `url`：课程详情/目录页 URL

可参考 `寒暑假期教师研修/config.json` 中的 5 门课。

**完成条件：** 专题页累计学时达到 10（解析当前/目标学时；`当前 >= 10` 或 `当前 == 目标`）。  
`courses` 用于选课播放，**不是**完成判定本身。

## 主流程

1. `_init_browser` → `_ensure_logged_in`（已有滑块登录）。
2. 打开 `class_id`，检测学时；已达标 → `_mark_course_complete` → 结束。
3. 按 `courses` 顺序处理未完成课程：
   - 新标签打开 `url`
   - 展开目录（`fish-collapse-header`）
   - 点击状态为「未开始」「进行中」的 `resource-item-train`
   - 播放：大播放按钮 → 「我知道了」→ 控制条 → 尽量 2 倍速
   - 轮询等待「再学一遍」
   - 关闭播放标签，回专题页刷新学时
4. 学时未满则继续下一节/下一门；满 10 → 完成。
5. 若学时未满但 `courses` 均已无未完成小节 → 警告日志后结束（避免死循环），任务置失败或保持进行中（实现时选失败并写明原因）。

## 窗口与会话

- 专题页窗口保留为 `list_window`（或主窗口）。
- 播放用站点新开标签 / `window.open`，`switch_to.window` 切换；播完关闭播放页并切回专题页。
- 禁止另起 WebDriver；登录态依赖同一 browser `user-data-dir`。

## 错误处理

| 场景 | 处理 |
|---|---|
| 缺少 `class_id` 或 `courses` | 任务失败 `status=1` |
| 登录失效 | 尝试重新登录后继续 |
| 视频页异常 / 找不到播放控件 | 关标签，换下一节/下一门，写日志 |
| 学时未满且课程耗尽 | 失败并提示需补充 `courses` 或人工检查 |
| 用户手动停止 | 现有 `request_stop`，关浏览器 |

## 改动面

| 层 | 改动 |
|---|---|
| 执行器 | 扩展 `backend/services/runners/zxzh_runner.py` |
| 前端 | 无强制改动；任务表单沿用 `class_id` / `courses` |
| 依赖 | 无新增（仍用 selenium / ddddocr / opencv） |

## 测试计划

1. 配置任务：`class_id` = 2026jjsqpx 专题 URL；`courses` 填参考 5 门课。
2. 有头模式：登录 → 打开专题 → 播未完成课 → 学时增长。
3. 学时已满账号：登录后应直接标记完成。
4. 缺 `class_id` / 空 `courses`：应失败并有明确日志。
5. 中途停止：浏览器关闭，任务可停止。

## 风险

- 页面 class 名带 hash（`index-module_*`），选择器需容忍前缀匹配。
- 视频控件（video.js）偶发弹层；需容忍「我知道了」等可选步骤超时。
- 学时统计有延迟；「再学一遍」后回专题页需短暂等待再读数。

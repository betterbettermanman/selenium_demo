# 子任务模版

> 用途：填写需求的**子任务**描述。子任务统一按全栈填写：按「模块 / 分类」分段，段内分点按前端、后端、联调三条线写**具体做什么**，不写问题描述、背景分析或排查过程。联调指**和外部系统联调**（第三方平台、外部 API、采集平台等），不是前后端联调。
>
> | 线 | 分点写什么 |
> | --- | --- |
> | 前端 | 要实现的页面交互、布局、文案、选中联动 |
> | 后端 | 要实现的数据来源、接口、计算口径、MOCK 改真实 |
> | 联调 | 和外部系统怎么对接：对接哪个平台 / API、取什么数据、字段口径怎么对齐、怎么验证 |
>
> 同一模块下前端、后端、联调写在一起，不要拆成多个任务；用不到的模块删除，模块内某条线没有内容可省略该条（没有外部系统对接就不写联调）。填写区可直接复制到任务系统；示例提交时删除。

---

## 填写区
【任务名称】：

【涉及端】：全栈

【模块 / 分类】：
- 前端：【具体做什么，一条一事】
- 后端：【具体做什么】
- 联调：【和哪个外部系统怎么对接，没有则省略】

【模块 / 分类】（如：公共问题、实时能耗总览）：
- 前端：【分点】
- 后端：【分点】
- 联调：【分点】

不做范围：
- 【本次明确不做的事】

---

## 分点写法

分点写动作（做什么），不写问题（现在哪里不对）。

正确写法：
- 前端：左边支路做成可选中、可取消选中，默认选中第一个根节点
- 后端：按本层表具 + 时间范围查询真实能耗，各层级数据不能相同
- 联调：对接抄表平台公网 API 取每日读数，核对表号、读数字段映射，验证识别完成后数据能入库

错误写法（描述问题，不要这样写）：
- 左边支路没法选中和取消选中
- 切换节点后右边数据不联动

错误写法（把联调当成前后端联调，不要这样写）：
- 联调：选中节点后请求查询接口，右侧渲染返回值

## 填写示例（提交时删除）

任务名称：能耗管理页面交互与真实数据对接
涉及端：全栈

公共问题：
- 前端：所有用到树 / 支路的页面实现支路可选中、可取消选中，默认选中第一个根节点，选中后右侧展示当前支路名称
- 后端：实现按本层表具 + 时间范围查询，各层级数据不能相同；水表查询出真实数据

实时能耗总览：
- 前端：实现支路选中 / 取消，选中后联动查询右侧数据；区间统计去掉较上期内容
- 后端：按选中支路表具和区间查询真实能耗，不返回各层相同数据

用能集抄：
- 前端：实现分支可选中，右侧展示当前查看的分支名称，默认选中第一个根节点
- 后端：按选中分支和本层表具出集抄数据

分时段用电集抄：
- 前端：EPE 只保留发电量、上网电量、上网电费，去掉自用部分；信息块高度对齐电量占比、电费构成；去掉分时段电价配置参考模块
- 后端：峰平谷按系统时段方案统计出数，不使用表端上报数据

参数监测与分析：
- 前端：监测参数查询复选框支持多选；树展示时去掉多余短横线
- 后端：补齐历史数据查询、监测参数、参数对比曲线的真实实现，支持报表导出

智能水表采集：
- 后端：采集任务按最近 24 小时窗口拉取抄表记录，取窗口内最新有效读数入库
- 联调：对接 aimcover 远程抄表平台公网 API，核对表号、读数、抄表时间字段映射，覆盖平台 0 点上报 + OCR 识别滞后的数据形态，验证识别完成后数据能入库

能源支路概况：
- 前端：实现树可选中，右侧跟随选中内容变化；文案改为上月用量、本月、本年、上年
- 后端：真实实现，不再 MOCK；只做电，水不做；返回当日前一日、当月前一月、当年上一年环比，曲线为选中回路每日均值负荷曲线（功率），最下面图表按能耗历史查询实现

同比环比分析：
- 前端：分析按钮前增加电 / 水切换组件，左侧计量网络跟随电或水变化，树加载默认不统计用量，分支选中后右侧跟随变化
- 后端：按电或水和选中分支做真实同比环比查询

用能与碳排放预算：
- 前端：预算年度、编制状态、刷新按钮做成横向一行分布
- 后端：新增页面对应后端接口，按原型和常规实现出数

碳资产管理 / 碳足迹核算：
- 前端：有效期至改为生效年份，去掉状态、第三方核查字段；「从碳核算同步生产阶段」暂时屏蔽
- 后端：未真实实现的接口改为真实数据，不再 MOCK

能耗折标统计 / 单耗分析 / 工作时段分析 / 单位面积能耗对标 / 人均能耗对标 / 能流分析 / 温室气体盘查：
- 后端：未真实查询的一并补齐，不再 MOCK；折标统计能源类型默认固定电、水，统计周期变化后按对应周期做范围查询；对标只按总量对标（电回路根节点）、只保留电；损耗分析、流向分项用真实数据实现；碳排放核算明细默认按范围二出数

不做范围：
- 前端不展示自用发电
- 后端能源支路概况不做水
- 碳足迹同步生产阶段本轮不做

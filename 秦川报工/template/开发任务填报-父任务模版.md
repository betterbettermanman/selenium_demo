# 父任务模版

> 父任务只写**需求背景**和**技术性描述**，页面 / 接口细节放到子任务，见 `开发任务填报-子任务模版.md`。


---

## 填写区

【父任务名称】：

### 1. 需求背景

要解决的问题、当前现状：
【现有能力是什么，哪里不对、不可用】。

需求详细描述（产品视角）：
【谁在什么场景下用，完成后能做什么】。

关键改动点（对其他功能的影响）：
1. 【公共能力或口径变化，影响哪些页面 / 接口】
2. 【MOCK 改真实、字段调整、模块下线等】

### 2. 技术性描述

方案要点：
- 【公共交互 / 默认态 / 联动怎么做】
- 【数据按什么查、按什么口径算，不要用哪类数】
- 【需要单独分支、新接口、配置项时写一句；没有则省略】

子任务拆解：
1. 【前端 / 后端 / 全栈】【子任务名称】：【覆盖哪些页面或接口】
2. 【前端 / 后端 / 全栈】【子任务名称】：【覆盖哪些页面或接口】

## 填写示例（提交时删除）

父任务名称：能耗管理模块真实数据实现与页面交互统一

### 1. 需求背景

要解决的问题、当前现状：
能耗相关页面已有布局，但树普遍不能选中，右侧不随左侧变化；各层级数据相同，水表查不出数，多个页面仍是 MOCK。

需求详细描述（产品视角）：
用户在实时能耗总览、用能集抄、参数监测、能源支路概况、同比环比等页面，选中支路后只看当前支路在所选时间范围内的真实数据。统计按系统配置，不用未下发方案的表端数据。

关键改动点：
1. 树 / 支路选中成为公共能力，影响所有计量网络树页面。
2. 查询改为按本层表具 + 时间范围取数，影响前后端口径。
3. MOCK 改真实实现；自用发电、碳核算同步等本轮不做。

### 2. 技术性描述

做：树选中公共交互；上述页面真实查询；峰平谷按系统时段方案统计。
不做：自用发电展示；碳足迹同步生产阶段；分时段电价配置参考模块。

方案要点：
- 默认选中第一个根节点，选中后右侧标题、表格、图表按当前节点刷新。
- 按节点绑定表具 + 时间范围查询；区间统计不展示较上期。
- 同比环比增加电 / 水切换，树跟随变化。

子任务拆解：
1. 前端：能耗管理相关页面功能细节调整
2. 后端：能耗查询真实数据对接
